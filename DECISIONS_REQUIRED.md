# Проблемы/доработки

1. Удаление/изменения объекта сейчас предусматривает только ошибку, 
   при которой объект не найден(404), если объект не был удален(или изменен) по какой-то другой причине мы это не обрабатываем,
   потому что service сейчас возвращает только True/False(при удалении).
   Потом это надо будет сделать через собственные исключения(exceptions) которые service будет вызывать в зависимости от того,
   по какой причне мы не смогли удалить(или изменить) объект, а router будет их обрабатывать и вызывать подходящий status code
